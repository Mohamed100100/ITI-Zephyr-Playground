# 10 — How to Create a Zephyr Project (Summary)

This is a short, end-to-end summary of the whole creation process. Read it
after `03 Create Project` and `04 CMake`. Every step links to the lesson that
explains it in depth.

> **Main reference:** [Zephyr documentation](https://docs.zephyrproject.org/)

---

## The 9 steps

### 1. Find the board target

```bash
west boards | grep -i <name>
```

### 2. Read the board Devicetree

Find the LED alias (`led0`, `rgb0`, ...) and the `compatible` string.

```bash
zephyr/boards/<vendor>/<board>/<board>.dts
```

See [08 Devicetree](../08_Devicetree/README.md).

### 3. Create the project folder

Use the ready-to-copy template:

```bash
cp -r 03_Create_New_Project/new_project ~/projects/my_app
cd ~/projects/my_app
```

Layout:

```
my_app/
├── CMakeLists.txt
├── prj.conf
├── src/
│   └── main.c
├── inc/
│   └── app_config.h
└── build/            ← generated by west build
```

See [03 Create New Project](../03_Create_New_Project/README.md).

### 4. Edit `CMakeLists.txt` (the 5 important lines)

```cmake
cmake_minimum_required(VERSION 3.28.0)

find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})
project(my_app)

target_sources(app PRIVATE src/main.c)
target_include_directories(app PRIVATE ${CMAKE_CURRENT_SOURCE_DIR}/inc)
```

See [04 CMake](../04_CMake/README.md).

### 5. Edit `prj.conf` — enable the needed subsystems

```conf
CONFIG_GPIO=y
CONFIG_LOG=y
CONFIG_LOG_DEFAULT_LEVEL=3
```

See [05 Kconfig vs Devicetree](<../05_Kconfig_vs_Devicetree_DTS/README.md>)
and [06 Kconfig deep dive](../06_KConfig/README.md).

### 6. Write `src/main.c` — use Devicetree macros, never hard-coded pins

```c
#define LED0_NODE DT_ALIAS(led0)
static const struct gpio_dt_spec led = GPIO_DT_SPEC_GET(LED0_NODE, gpios);
```

See [03 Create New Project](../03_Create_New_Project/README.md) and
[08 Devicetree](../08_Devicetree/README.md).

### 7. Build from the project folder (workspace can be elsewhere)

```bash
source ~/zephyrproject/.venv/bin/activate
export ZEPHYR_BASE=~/zephyrproject/zephyr

west build -p always -b <board> -d build .
```

See [04 CMake](../04_CMake/README.md) §7.

### 8. Flash and monitor

```bash
west flash -d build
```

### 9. Inspect the result when something is wrong

```bash
cat build/zephyr/.config        # final Kconfig
cat build/zephyr/zephyr.dts     # final merged Devicetree
```

See [04 CMake](../04_CMake/README.md) §9 and
[05 Build Configuration Outputs](<../05_Kconfig_vs_Devicetree_DTS/Build_Configuration_Outputs.md>).

## Quick reference

| Step | Tool / file | Lesson |
|---|---|---|
| Find board | `west boards` | 03 |
| Read hardware | `.dts` | 08 |
| Project skeleton | `new_project/` template | 03 |

## Important commands

```bash
# environment (every new terminal)
source ~/zephyrproject/.venv/bin/activate
export ZEPHYR_BASE=~/zephyrproject/zephyr

# build
west build -b <board> -d build .            # build into ./build
west build -p always -b <board> -d build .  # clean build
west build -t menuconfig -d build           # edit Kconfig (terminal)
west build -t run -d build                  # run on native_sim / QEMU

# flash
west flash -d build

# inspect
cat build/zephyr/.config
cat build/zephyr/zephyr.dts
```
